# Even-Odd-Java

## Description
This Java program checks whether a given number is even or odd.

## Logic
- If a number is divisible by 2, it is an Even number.
- Otherwise, it is an Odd number.

## Files
- `EvenOdd.java` - Main Java program
- `README.md` - Project documentation
- `.gitignore` - Ignores unnecessary files

## How to Run

### Compile
```bash
javac EvenOdd.java
